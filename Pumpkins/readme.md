# Pumpkins 🎃
This folder has all the files for the pumpkins portion. Below is a brief outline of everything.

 - `Pumpkins.py` - This is the main python script used in this task to generate answers and plots.
 - `requirements.txt` - This text file lists all the modules used by the script `Pumpkins.py`.
 - `output.html` - This file has the report with the answers and plots and commentary of the code.
    - `output.qmd` - This file is provided if needed to rebuild the .html file.
 - `pumpkins_filtered.csv` - CSV containing the filtered output data.
 - `.png` files - PNGs of the various plots produced by the program.
