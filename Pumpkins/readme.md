# Pumpkins 🎃
This folder has all the files for the pumpkins portion. Below is a brief outline of everything.

 - [Pumpkins.py](Pumpkins.py) - This is the main python script used in this task to generate answers and plots.
 - [requirements.txt](requirements.txt) - This text file lists all the modules used by the script `Pumpkins.py`.
 - [output.html](output.html) - This file has the report with the answers and plots and commentary of the code.
    - [output.qmd](output.md) - This file is provided if needed to rebuild the .html file.
 - [/outputs](outputs/) - Folder containing the outputs of the code.
    - [.png](outputs) files - PNGs of the various plots produced by the program.
    - [pumpkins_filtered.csv](outputs/pumpkins_filtered.csv) - .csv file containing the filtered output dataset from the code.
 - [/pumpkins_datasets](pumpkins_datasets) - Folder containing only the dataset assigned to me, used in this exercise.
